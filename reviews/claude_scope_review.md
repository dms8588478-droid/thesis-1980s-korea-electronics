# 0. 검증 결론

새 목차는 **보유 사료와 정반대 방향**을 가리킵니다. 세 가지가 동시에 걸립니다.

**첫째, 사료 기반이 비어 있습니다.** 제2장(미일 통상마찰·일본 기술이전·지식재산권)은 아홉 절 중 세 절인데, 이 폴더에 대응 사료가 **0건**이고 `primary_sources.md` P01~P08에도 **0줄**입니다. 외교문서·통상자료·특허자료가 대장에 한 항목도 없습니다. 반대로 폴더의 최대 자산인 ETRI 기관사 계열 10종은 3장 2절 **한 절**에만 걸립니다.

**둘째, 입증 부담이 비대칭입니다.** 지정하신 6개 주장 중 4개가 **부재 증명** 또는 **국제 인과 연쇄**입니다. "통제력을 잃었다", "통로가 차단됐다"는 없음을 증명하는 명제라 석사 분량에서 가장 다루기 어려운 유형입니다.

**셋째, 제목에 시대착오 개념이 들어 있습니다.** '안보화'는 1990년대 코펜하겐학파의 분석 용어입니다. 킥오프 문서 스스로 예상 질문에 "현재주의를 어떻게 통제할 것인가"를 적어 놨는데, 제목이 그 혐의를 자초합니다.

**참고로 두 사료 대장의 현재 상태:** `secondary_sources.md`는 **전 항목 미체크**입니다. 한 편도 읽지 않았고, 직접 선행연구는 3편뿐입니다(D06 기준 5편). 그리고 **미일 통상·국제정치경제·기술이전 관련 문헌이 0편**입니다. `timeline_1980s_electronics.md`는 1980~89년 전 항목이 `[확인필요]`로, 새 목차의 1979~1988 시기 구획을 뒷받침할 연표가 없습니다.

# 2. 시대착오 위험 개념

| 개념 | 출처·시점 | 위험 등급 | 처리 |
|---|---|---|---|
| **안보화(securitization)** | 코펜하겐학파, 1990년대 | **최고 — 제목에 있음** | 분석 개념임을 머리말에서 명시하거나 제목에서 제거 |
| **기술안보 / 경제안보** | 2010~2020년대 정책어 | **최고** | 본문 사용 금지. 당대 행위자 언어로 대체 |
| 위험 분담자(risk-sharer) | 현대 정책경제학 | 높음 | 당대 문서의 표현으로 환원 |
| 학습효과 | 정책학·조직론 | 높음 | 인과 주장을 대체하는 편의어로 쓰지 말 것 |
| 진영질서의 균열 / 냉전 후기 | 사후적 시대구분 | 중간 | 시기 구분어로만, 인과어로 쓰지 말 것 |

| 기술 획득 '통로' | 분석 은유 | 낮음 | 지표를 정의하면 사용 가능 |
| **재벌** | **당대 용어** | 낮음 | 시대착오 아님. 분석 범주로서 정의만 필요 |
| **기술집약화** | 당대 용어 가능성 높음 | — | **확인되면 논문의 자산** |

**핵심:** '안보화'와 '기술자립'은 성격이 정반대입니다. 앞은 연구자가 사후에 씌우는 틀이고, 뒤는 당대 행위자가 실제로 썼을 가능성이 있는 말입니다. D06 §4.2가 "당대 용어를 따옴표로 표시하고 그 의미가 시기와 행위자에 따라 달라지는 과정을 분석한다"고 정리한 방식은 후자를 가리킵니다.

**제목이 '기술자립'이 아니라 '안보화'를 택한 것이 이 목차의 가장 큰 방법론적 결정이며, 지도교수 스타일과 어긋나는 지점입니다.**

**반대 설명이 강합니다.** ① 은행 민영화 이후에도 정책금융·여신관리·주거래은행 제도가 유지되었다면 "통제력 상실"이 아니라 "수단 교체"입니다. ② 1980년대 산업합리화 조치는 정부가 여전히 개별 기업의 진퇴를 결정한 사례입니다. ③ 무엇보다 — **정부가 통제력을 잃었다면 왜 1986년에 정부 주도 공동개발사업이 성립했는지**를 설명해야 합니다. 이 주장은 논문 자신의 3장과 충돌합니다.

**판정:** 현재 형태로는 **입증 불가**. "통제 수단이 직접 금융배분에서 연구개발 자금 지원으로 이동했다"처럼 **부재가 아니라 변화**를 주장하는 문장으로 바꿔야 검증 가능해집니다.

## 3-3. 「일본의 기술이전 통로가 축소·차단됐다」

**분류: C + X** — 부재 증명이며, 주체가 모호합니다.

먼저 분해해야 합니다. **차단의 주체가 일본 정부인가, 개별 일본 기업인가?** 전자는 수출규제·법령의 문제이고 후자는 상업적 판단입니다. 둘은 사료도 함의도 완전히 다릅니다.

| 항목 | 내용 |
|---|---|
| 생산주체 | 한국: 과학기술처·상공부(기술도입 인가 담당), 도입 당사자 기업 / 일본: 통상산업성, 외무성 / 국제: COCOM |
| 문서 유형 | **기술도입 인가 통계·인가 대장**(핵심), 기술도입 계약 신고 자료, 외교 공한, 통상 협의 기록, 수출관리령 관련 자료 |
| 예상 소장처 | 국가기록원, 외교사료관(30년 공개분), 국립중앙도서관(과학기술연감·상공백서 통계), 일본 국립공문서관·외무성 외교사료관 |
| 검색어 | `기술도입 인가` `기술도입 실적` `대일 기술도입` `기술제휴` `기술도입 신고` `수출관리령` `COCOM` `전략물자` |
| 반대 사료 가능성 | **매우 높음** |

**결정적 반대 사료:** 연도별 대일 기술도입 인가 건수·금액 통계입니다. 1984~86년 대일 기술도입이 **증가하거나 유지되었다면 '차단' 주장은 즉시 폐기**됩니다. 이 통계는 과학기술연감·상공백서에 실릴 가능성이 높고 비교적 쉽게 확보됩니다.

**판정:** **가장 먼저 반증 시도를 해야 할 주장입니다.** 통계 한 장으로 무너질 수 있고, 무너지면 제2장 2절과 2장→3장 인과 고리가 함께 무너집니다. 살아남더라도 "차단"이 아니라 "특정 기술 영역에서의 거래 거절 사례"로 축소될 가능성이 높습니다.

## 3-4. 「미일 반도체협정이 한국 공동개발에 영향을 미쳤다」

**분류: C + X** — 국제 인과 연쇄로, 석사 논문에서 가장 입증하기 어려운 형태입니다.

| 항목 | 내용 |
|---|---|
| 생산주체 | 과학기술처, 상공부, 외무부, 주미·주일 대사관, 참여 기업 |
| 문서 유형 | **한국 정책문서 안의 국제환경 서술 부분**(핵심), 외교 전문·보고, 통상 협의 기록, 당대 언론 보도 |
| 예상 소장처 | 대통령기록관, 국가기록원, 외교사료관, 네이버 뉴스 라이브러리·빅카인즈, 미국 측 자료(NARA, 레이건 도서관, USTR·ITC 간행물) |
| 검색어 | `미일 반도체협정` `반도체 협정` `덤핑` `제3국 시장` `대미 통상마찰` `통상압력` `반도체 수출` |
| **즉시 가능** | **폴더의 공동개발안(1986.08.22)에 국제환경 서술이 있는지 확인.** 협정 체결 직후 시점 문서 |
| 반대 사료 가능성 | 높음 |

**입증 요건이 까다롭습니다.** 이 주장이 성립하려면 **한국 측 당대 문서가 미일협정을 명시적으로 언급하며 그것을 사업 추진 이유로 제시**해야 합니다. 정책문서는 대개 국제 정세를 배경으로만 짧게 쓰고 인과를 명시하지 않습니다. 언급이 없으면 "영향을 미쳤다"는 연구자의 추론이 됩니다.

**반대 설명:** 공동개발 구상이 협정 체결(1986년) 이전부터 진행되었다면 인과 방향이 성립하지 않습니다. **공동개발안 문서의 '추진경위' 항목이 이것을 결정합니다.**

**판정:** 폴더의 12MB 문서 하나로 살거나 죽는 주장입니다. 정독이 최우선.

## 3-5. 「기술자립 담론이 기술을 안보 문제로 전환했다」

**분류: C + H + A + X** — 네 겹입니다.

- ① '기술자립'이 당대 용어였다 → **V, 검증 가능**
- ② 그 용어가 널리 유통되었다 → **V, 빈도 분석으로 검증 가능**
- ③ 당대 행위자가 기술을 **안보 언어로** 말했다 → **V, 검증 가능하나 미확인**
- ④ 담론이 인식을 '전환'시켰다 → **C X, 입증 곤란**

| 항목 | 내용 |
|---|---|
| 생산주체 | 대통령(연설·연두교서), 과학기술처·상공부, 언론, 기업 홍보물, 학계 |
| 문서 유형 | 대통령 연설문, 정책 백서 서문·총론, 신문 사설·기획기사, 사내보, 과학기술연감 총설 |
| 예상 소장처 | 대통령기록관(연설기록), 국가기록원, 네이버 뉴스 라이브러리, 빅카인즈, 국립중앙도서관 |
| 검색어 | `기술자립` `자립기술` `기술입국` `기술개발 없이는` `기술 종속` `산업 안보` `경제 안보` `국가 생존` |
| 반대 사료 가능성 | 중간 |

**핵심 검증:** ③이 관건입니다. 당대 문서에 **`안보`·`생존`·`종속` 계열 어휘가 기술 문맥에서 실제로 나타나는지**를 확인해야 합니다. 나타나면 '안보화' 주장이 사료에 발을 딛습니다. 나타나지 않고 `경쟁력`·`수출`·`부가가치` 계열만 있다면, 안보화는 연구자의 사후 재기술이며 **제목에서 빼야 합니다.**

**반대 설명:** '기술자립'이 안보가 아니라 **무역수지·로열티 부담** 문맥에서만 쓰였을 가능성. 이 경우 논문은 안보사가 아니라 통상사가 됩니다.

**판정:** ①②③은 이번 달에 검증 가능합니다. ④는 어떤 사료로도 직접 입증되지 않으므로 **주장 형태를 "담론이 인식을 바꿨다"에서 "정책 정당화에 이런 언어가 동원되었다"로 낮춰야** 합니다.

## 3-6. 「국가가 지시자에서 위험분담자로 바뀌었다」

**분류: C + H + A** — 그리고 **전제 사실 자체가 미확인**입니다(D9).

| 항목 | 내용 |
|---|---|
| 생산주체 | 과학기술처, 상공부, 연구조합, 참여 기업 |
| 문서 유형 | **1980년대 초 연구조합 설립 시도 관련 문서**(가장 중요), 공동개발안의 비용분담 조항, 특정연구개발사업 처리규정, 출연금 집행 자료 |
| 예상 소장처 | 국가기록원, 대통령기록관, 관보(고시·인가), 국립중앙도서관(과학기술연감) |
| 검색어 | `연구조합` `산업기술연구조합` `공동연구개발` `정부출연금` `민간부담금` `기업분담` `위험부담` |
| 반대 사료 가능성 | 높음 |

**전제가 비어 있습니다.** "지시자였다가 바뀌었다"를 말하려면 **① 이전에 지시했다는 증거**와 **② 그 시도가 실패했다는 증거**가 있어야 합니다. D9가 지목한 "1980년대 초 연구조합 무산"이 그 자리인데, **어느 문서에도 무산된 조합의 이름·연도·경위가 없습니다.**

**반대 설명 두 가지.** ① 정부 출연금 비율이 높으면 '위험 분담'이 아니라 여전히 '주도'입니다. **공동개발안의 분담 비율이 이것을 판정합니다.** ② 성과 소유·제3자 공개 규칙이 정부에 유리하면, 위험은 분담하되 통제는 유지한 것이 됩니다 — '지시자→위험분담자'라는 이항 대립 자체가 성립하지 않습니다.

**판정:** 두 이항 대립(지시자/위험분담자)은 D06 §4.1이 경계한 양자택일 형식입니다. **비율과 조항이라는 확인 가능한 단위로 환원**해야 논문이 됩니다.
