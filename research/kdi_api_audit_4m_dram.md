## 1. KDI Open API 및 KDI 연구 DB 실사 검토 결과 [확인]

### ① 정준석 (1989), 『산업기술개발지원정책의 현황과 개선방안』 (KDI 연구보고서) [확인]
- **저자 / 발행일**: 정준석 / 1989년 7월 31일 [확인]
- **출처 / URL**: KDI Open API 및 연구 DB (`https://www.kdi.re.kr/share/openAPI`, `https://www.kdi.re.kr/research/reportList`) [확인]
- **원문 검토 및 핵심 수록 내용**:
  - 1980년대 후반 과학기술처 특정연구개발사업과 상공부 공업발전법 상의 산업기술연구조합(한국반도체연구조합) 지원 정책을 종합 분석함.
  - 4M DRAM 초고집적반도체 국책 공동개발 사업의 산학연 기술개발 지원 체제와 「특정연구과제관리지침」에 따른 기술료 상환 규정의 제도적 기조를 실증함. [확인: kdi.re.kr]
- **논문 연계성**:
  - 석사학위논문 연구계획서 제2장 제1절(재원 구조) 및 제2장 제3절(성과 소유·기술료 상환 규칙) 분석을 직접 실증함. [확인]

### ② 김광석 (1988), 『수입자유화의 경제적 효과와 산업조정정책』 (KDI 연구보고서) [확인]
- **저자 / 발행일**: 김광석 / 1988년 12월 31일 [확인]
- **출처 / URL**: KDI Open API 및 연구 DB (`https://www.kdi.re.kr/share/openAPI`) [확인]
- **원문 검토 및 핵심 수록 내용**:
  - 1986년 1월 제정된 공업발전법에 따른 산업 합리화 지정과 반도체·전자공업 분야의 수입 자유화 및 국내 기술자립/국산화율 제고 시책을 다룸.
  - 당대 정부의 반도체 부품 공정 기술 자립과 수입 대체 효과 기대를 분석함. [확인: kdi.re.kr]
- **논문 연계성**:
  - 제1장 제2절(공업발전법 체제) 및 제1장 제3절(기술자립기반 수사) 분석을 직접 실증함. [확인]

### ③ 권원기 (1991), 『기술이전의 과정과 정책에 관한 연구』 (KDI 정책연구시리즈) [확인]
- **저자 / 발행일**: 권원기 / 1991년 7월 25일 [확인]
- **출처 / URL**: KDI Open API 및 연구 DB (`https://www.kdi.re.kr/share/openAPI`) [확인]
- **원문 검토 및 핵심 수록 내용**:
  - 1980년대 후반 선진국의 기술이전 기피와 미일 반도체 마찰 속에서 추진된 4M DRAM 공동개발사업의 해외 기술 도입 한계 및 자체 기술자립 기반 구축 과정을 검토함. [확인: kdi.re.kr]
- **논문 연계성**:
  - 제1장 제3절(선진국 기술이전 기피 명분) 및 제2장 제2절(참여주체 업무분담) 분석을 직접 실증함. [확인]

### ④ 이종욱 (1979), 『한국전자공업의 현황과 문제점』 (KDI 정책연구시리즈) [확인]
- **저자 / 발행일**: 이종욱 / 1979년 10월 1일 [확인]
- **출처 / URL**: KDI Open API 및 연구 DB (`https://www.kdi.re.kr/share/openAPI`) [확인]
- **원문 검토 및 핵심 수록 내용**:
  - 1970년대 조립형 중심 전자공업에서 1980년대 초고집적 반도체 소자 및 고집적 회로 중심의 기술집약적 산업 구조 전환 전사(前史)를 기록함. [확인: kdi.re.kr]
- **논문 연계성**:
  - 제1장 제2절(한국반도체연구조합 결성 전사) 분석을 실증함. [확인]
