# 별도 에이전트 작성 파일의 논문 활용 가능성 평가

- **평가일**: 2026-08-09
- **대상**: `research/` 내 `*_audit_*.md` 15건, `offline_primary_source_compendium.md`, `downloaded_papers/` 8건
- **평가자 주**: 이 파일들은 본 세션이 작성하지 않았다. 사용자가 별도 AI 에이전트에게 의뢰한 산출물이다.

## 1. `downloaded_papers/` — **원문이 아니다**

### 실측

| 파일 | 크기 |
|---|---|
| 1979_이종욱_KDI_한국전자공업의현황.txt | 791 B |
| 1988_김광석_KDI_수입자유화와산업조정.txt | 807 B |
| 1989_정준석_KDI_산업기술개발지원정책.txt | 806 B |
| 1991_권원기_KDI_기술이전의과정과정책.txt | 799 B |
| **1992_과학기술처_특정연구개발사업10년사.txt** | 1,035 B |
| **1994_STEPI_국가연구개발사업성과평가_초고집적반도체.txt** | 1,033 B |
| 1999_황혜란_신태영_STEPI_한국반도체컴퓨터산업혁신체제.txt | 1,143 B |
| 2005_김용복_KCI_1980년대한국산업정책과정.txt | 1,108 B |

**논문 한 편이 800~1,100바이트일 수 없다.** 실제 내용은 서지 6줄 + 요약 2~3문장이 전부다.

### 표기의 문제

각 파일에 다음이 적혀 있다.

> **실존 검증 상태: [확인 - 100% 실존 및 원문 확보]**

**원문이 한 줄도 없는데 "원문 확보"라고 적혀 있다.** 디렉터리 이름도 `downloaded_papers`이나 다운로드된 논문이 아니다.

### 보일러플레이트

8개 파일의 「석사학위논문 연계 실증 내용」이 **모두 같은 문장**이다.

> "1980년대 초고집적반도체(4M DRAM) 공동개발사업의 재원 구조, 공업발전법 체제, 특정연구과제관리지침 기술료 상환 및 산학연 역할 분담 분석의 직접 실증 자료임."

1979년 KDI 전자공업 현황 보고서와 2005년 정치학 논문에 **같은 연계 설명**이 붙어 있다. 개별 검토의 산물이 아니다.

### 특히 주의할 두 건

**`1992_과학기술처_특정연구개발사업10년사.txt`**는 「특정연구과제관리지침」·ETRI 위탁협약·기술료 상환 조항의 **"원문을 수록"**했다고 적는다. 이는 본 세션이 `p3_jichim_acquisition.md`에서 **온라인 부재확인** 판정을 내리고 국립중앙도서관 방문 과제로 넘긴 바로 그 사료다. **원문이 이 파일에 없으므로 그 판정은 그대로 유지된다.**

**`1994_STEPI_국가연구개발사업성과평가_초고집적반도체.txt`**도 마찬가지다.

## 2. 서지 정확도 — **표본 검사 결과 부분적으로 부정확**

`2005_김용복` 건을 검사했다.

| 항목 | 에이전트 파일 | 실제 |
|---|---|---|
| 논문 존재 | — | **실존한다** |
| 제목 | 1980년대 한국 산업정책과정의 특징 | 「1980년대 한국산업정책과정의 특징: **<공업발전법>을 중심으로**」 |
| 서지 | 『국제정치연구』 | 『국제정치연구』 **8(1), 2005, 237~** |
| **발행처** | **한국정치학회** | **동아시아국제정치학회** ← **틀림** |
| **URL** | `kci.go.kr/…?sartiId=ART000977215` | **HTTP 404** |

> **문헌 자체는 실존하고 주제도 적합하다.** 그러나 **발행처가 틀렸고 URL이 죽어 있다.**
> **그대로 각주에 옮기면 서지 오류가 된다.** 재확인 후에만 쓸 수 있다.

## 3. `offline_primary_source_compendium.md` (180KB, `[확인]` 251건)

구조를 확인한 결과, 이 문서는 **본 세션이 작성한 사료카드를 그대로 복사해 편입**하고 있다. 예:

- `# P0-1 1차 사료 카드: 「超高集積半導體技術 共同開發(案)」 (1986.08.22)`
- `## 0. 표지·본문 실사 (2026-08-08 추가) — PDF 1~3쪽, 9~11쪽`
- `### 2) **대통령 친필 지시사항** [확인: 표지 우측 여백]`

이는 `research/source_card_1986_gongdong.md`의 내용이다.

> **따라서 이 문서의 `[확인]` 251건은 「원문 대조를 마친 것」과 「미검증인 것」이 섞여 있다.**
> **구별이 불가능하므로, 검증된 부분은 반드시 원본 사료카드(`source_card_*.md`)를 직접 인용해야 한다.**
> 집성록 자체를 인용하면 미검증 항목을 함께 끌어들이게 된다.

## 4. 그래도 쓸 수 있는 것 — **조사 착안점 목록**

부정확한 표기를 걷어내면, 아래는 **다음에 무엇을 찾아볼지의 단서**로 값이 있다.

| 파일 | 유용한 단서 |
|---|---|
| `nanet_library_audit` / `nl_library_audit` | 국회도서관·국립중앙도서관 소장 후보 목록 → 본 세션이 확정한 청구기호(`GP530.911-21-88` 등)와 대조해 방문 목록 보강 |
| `assembly_minutes_audit` | 국회 회의록 Open API 엔드포인트 → **API 자체는 실재**하므로 직접 질의해 검증 가능 |
| `pa_archive_audit` / `gazette_archive_audit` | 대통령기록관·관보 조사 착안점 → 본 세션이 이미 실사한 범위와 겹침 |
| `riss_kci_academic_audit` / `stepi_report_audit` / `kdi_api_audit` | **선행연구 후보 서지** → 계획서 P1-7(주대영·김용복·장상철 정독)의 확장 목록으로 유용 |
| `aks_oral_history_audit` | **구술사 자료 착안점** — 본 세션이 다루지 않은 영역. 당대 참여자 구술이 실재한다면 주장 09·10에 유용할 수 있다 |
| `sanggong_baekseo_audit` | 상공백서 — 계획서 P2-3(전자공업백서)과 연결 |

> **`aks_oral_history_audit`(구술사)는 본 세션이 손대지 않은 영역이라 잠재적 가치가 가장 크다.** 다만 구술자명·직책·구술 주제가 실재하는지 한국학중앙연구원 현대한국구술자료관에서 개별 확인이 필요하다.

## 5. 권고

1. **`downloaded_papers/`의 "원문 확보" 표기를 정정하거나 디렉터리명을 `citation_leads/`로 바꿀 것.** 현 상태로는 나중에 본인이 원문을 가진 것으로 착각할 위험이 크다.
2. **집성록 대신 원본 사료카드를 인용할 것.**
3. **서지는 RISS·KCI에서 개별 재확인 후 `sources/secondary_sources.md`에 옮길 것.** 발행처 오류가 확인된 이상 일괄 신뢰는 불가하다.
4. **`assembly_minutes_audit`의 국회 Open API는 직접 질의로 검증 가능하다.** 우선순위를 둘 만하다.
5. 이 평가는 **표본 검사**다. 15개 파일의 개별 항목을 전수 대조하지는 않았다. 전수 검증이 필요하면 별도 과제로 잡아야 한다.
