# 조사 노트 — 동아디지털아카이브 본문 접근 가능성 (실사)

**조사일** 2026-08-12
**대상** `donga.com/archive/newslibrary` (동아디지털아카이브 뉴스라이브러리)
**목적** 논문 작성에 필요한 기사 **본문**을 이 사이트에서 얻을 수 있는지 확인
**방법** 검색·열람 엔드포인트 직접 호출 실사 (셸 curl)

---

## 결론 먼저

| 기능 | 가능 여부 | 조건 |
|---|---|---|
| 키워드+기간 검색 (제목·일자·면수·섹션) | **가능** | 로그인 불필요 |
| 기사 **본문 텍스트** (1920~2009년) | **존재 확인** | **로그인 필요** |
| 지면 PDF 뷰어 | 있음 | 로그인 필요 추정 |

**본문은 있다. 그러나 1920~2009년 기사 본문은 로그인 게이트 뒤에 있다.**
열람 엔드포인트가 반환한 실제 문구:

> 「1920년 ~ 2009년 기사는 **로그인** 후 열람하실 수 있습니다.」

동아일보 회원 가입·로그인은 연구자 본인이 해야 한다(본 조사는 계정 생성을 하지 않았다).
로그인만 하면 **「원문」(한자 혼용 OCR 텍스트)과 「한글변환」(두음법칙 자동 적용) 두 모드**로
본문 텍스트가 제공된다 — 지면 이미지가 아니라 텍스트다. 사이트 스스로
「한글 변환시 두음법칙이나 동자이음 적용이 불완전할 수 있습니다」라고 밝히므로,
중앙일보와 마찬가지로 **인용 전 지면 대조**가 필요하다.

## 검색 인터페이스 (로그인 불필요 — 자동화 조사 가능)

GET 파라미터로 동작한다:

```
https://www.donga.com/archive/newslibrary?query=<검색어>&range=1
  &search_date=5&sdate=YYYYMMDD&edate=YYYYMMDD&sorting=2&option=1
```

- `sdate`/`edate`는 **YYYYMMDD 형식만** 유효 (하이픈·점 형식은 무시되고 전 기간 검색됨 — 주의)
- `sorting=2` 오래된순, `l=30` 목록 건수
- 결과 항목: 제목·일자·면수·섹션 + 열람 링크 (`view?ymd=...&mode=...`)
- 본문 열람은 `view?idx=<날짜/기사ID/판>` AJAX 엔드포인트

## 논문 작업에의 함의

1. **중앙일보 단일 계열의 한계를 보완할 두 번째 신문 계열이 확보 가능하다.**
   같은 사건의 보도 일자·수치를 두 신문에서 대조하면 신문 사료의 신뢰도가 한 단계 올라간다.
2. **선행 조사(제목 수준)는 지금 바로 가능하다** — 로그인 없이 검색되므로,
   중앙일보 인용 후보 18건에 대응하는 동아일보 기사의 존재와 일자를 목록화할 수 있다.
3. **본문 확보는 연구자의 로그인 후 작업이다.** 회원가입 → 로그인 → `view` 페이지에서
   원문/한글변환 텍스트 열람. 무단 전재 금지 고지가 있으므로 **인용 범위는 학술 인용
   관행(출처 명시, 필요 최소한)을 지킨다.**
4. 네이버 뉴스 라이브러리(경향·동아·매일경제·조선·한겨레)와 달리 **동아 자체 아카이브는
   텍스트 모드가 있어** 검색·복사에 유리하다. 다만 동일하게 OCR 기반이므로 지면 대조 원칙 유지.
