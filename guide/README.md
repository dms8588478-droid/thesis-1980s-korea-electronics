# 고려대 사학과 석사논문 실행 가이드

> 대상: **컴퓨터/코딩 비전공 대학원생**(고려대 사학과). 1980년대 한국 반도체 산업 석사논문.

## 먼저 볼 문서

- **내일 바로 시작:** [`tomorrow_thesis_kickoff_guide.md`](tomorrow_thesis_kickoff_guide.md)
  Python·R·Quarto·Codex 설치부터 주제 토론, Quarto Book, 사료대장, Zotero 인용, 주장 카드, Git 커밋까지 연결한다.
- **이전 Claude/MCP 실습안:** [`2h_thesis_ai_guide.md`](2h_thesis_ai_guide.md)
  초기 환경을 보존한 참고문서다. 현재 논문 작업은 위의 최신 킥오프 가이드를 우선한다.

## 준비물 (시작 전 확인)
- 노트북(Windows 10/11 또는 Mac), 인터넷, 관리자 권한.
- 학교에서 복사·스캔해 온 **사료 텍스트**(삼성전자 20년사, 전자공업백서 등) — PDF 또는 한글/워드.
- ChatGPT 로그인 계정(Codex CLI 인증용).

## 진행 순서

1. 오늘 밤: Git·VS Code·Python·R·Quarto·Node·Codex·Zotero 설치
2. 내일 10~15분: 제목 강도, 핵심 기여, 작업가설, 자료 부족 시 축소안 결정
3. 이후 2시간: Quarto Book → 사료대장 5건 → 실제 인용 1건 → 주장 카드 3건 → 렌더·커밋

## 핵심 원칙 (미리 새겨둘 것)
1. **AI는 조수지 저자가 아니다.** 논지와 해석은 본인이 만든다.
2. **원문에서 쪽수로 확인 못 한 인용은 절대 쓰지 않는다.** AI가 제안한 내용은 검증 전까지 `후보`다.
3. **사사(社史)는 자기서술.** 정부 백서·타사 사사·통계로 반드시 교차검증한다.
