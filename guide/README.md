# 2시간 완성 — AI로 석사논문 쓰기 (Python 설치 → 논문 작성법)

> 대상: **컴퓨터/코딩 비전공 대학원생**(고려대 사학과). 1980년대 한국 전자산업 석사논문.
> 목표: 2시간 안에 AI 연구환경을 세팅하고, **환각(거짓 정보) 없이** 사료를 분석해 논문 뼈대까지 만든다.
> 본문: **[`2h_thesis_ai_guide.md`](2h_thesis_ai_guide.md)** ← 이 파일 하나를 열어두고 순서대로 따라가면 된다.

## 준비물 (시작 전 확인)
- 노트북(Windows 10/11 또는 Mac), 인터넷, 관리자 권한.
- 학교에서 복사·스캔해 온 **사료 텍스트**(삼성전자 20년사, 전자공업백서 등) — PDF 또는 한글/워드.
- 이메일 계정(Claude 가입용). *유료 구독(Claude Pro)이면 더 원활하지만 무료로도 실습 가능.*

## 2시간 타임라인
| 시간 | 단계 | 내용 |
|---|---|---|
| 0:00–0:10 | STEP 0 | 오늘의 목표·결과물 미리보기, 원리 이해 |
| 0:10–0:30 | STEP 1 | Python + uv + Node 설치 |
| 0:30–0:45 | STEP 2 | 논문 저장소(GitHub) 내려받고 폴더 이해 |
| 0:45–1:15 | STEP 3 | Claude(AI) 설치 + **MCP 서버 3종을 노트북에 직접 설치·검증** + 연결 |
| 1:15–1:30 | STEP 4 | 사료를 텍스트로 만들고 AI가 정밀검색하게 하기 |
| 1:30–1:50 | STEP 5 | AI로 가설·목차 설계 (환각 방지 규칙) |
| 1:50–2:00 | STEP 6 | 논문 작성법 — 인용·각주·서지·교차검증 |

## 핵심 원칙 (미리 새겨둘 것)
1. **AI는 조수지 저자가 아니다.** 논지와 해석은 본인이 만든다.
2. **원문에서 쪽수로 확인 못 한 인용은 절대 쓰지 않는다.** (AI가 지어낸 출처 = 연구부정)
3. **사사(社史)는 자기서술.** 정부 백서·타사 사사·통계로 반드시 교차검증한다.
