# 00 — 연구 개요

> 지도교수 면담용 잠정안. 제목과 작업가설은 사료 타당성 시험을 거쳐 확정한다.

## 가제

**「1986~1989년 4M DRAM 공동개발사업의 형성과 운영 — 정부·ETRI·참여기업의 관계를 중심으로」**

## 연구대상과 범위

- 중심 시기: 1986~1989년
- 전사: 1983년 전후 국내 기업의 DRAM 진입과 국가 연구개발정책 변화
- 대상: 4M DRAM 공동개발사업
- 행위자: 과학기술처, ETRI, 반도체연구조합, 삼성·금성·현대와 참여 대학
- 외부 환경: 미·일 반도체 경쟁과 기술·통상환경은 사업 형성에 필요한 배경으로만 다룬다.

## 주질문

4M DRAM 공동개발사업의 제도와 운영 규칙은 어떤 배경에서 형성됐고, 정부·ETRI·반도체연구조합·참여기업의 관계 속에서 어떻게 실행·조정됐는가?

## 하위질문

1. 공동개발은 누가 어떤 문제를 해결하기 위해 제안했는가?
2. 자금, 업무, 성과소유, 기술공유와 제3자 공개 규칙은 어떻게 정해졌는가?
3. 공동개발과 참여기업의 독자개발은 실제로 어떤 관계였는가?
4. 사업 운영의 협력·경쟁·갈등과 조정은 어떤 당대 자료로 확인되는가?
5. 이 사례는 1980년대 후반 정부–기업 관계를 기존 국가주도/민간주도 설명과 어떻게 다르게 보게 하는가?

## 작업가설

- ‘조정된 경쟁’은 결론이 아니라 검증할 후보 개념이다.
- 기업·연구조합의 발의, 정부·ETRI의 조정, 공동·독자개발의 관계를 보여주는 당대 자료가 확보될 때만 본문 논지로 발전시킨다.
- 반대 사료가 나오면 가설을 수정하거나 폐기한다.

## 연구사적 기여 후보

1. 기술성공사가 아니라 공동개발의 제도와 행위자 관계를 복원한다.
2. 국가주도/민간주도 이분법보다 제안·규칙·운영·조정의 실제 과정을 검토한다.
3. 당대 기록과 후대 기관사·사사의 공로 서술을 구분한다.

## 방법과 증거 기준

- 문헌사료의 외적·내적 비판과 생산맥락 확인
- 정부·연구기관·연구조합·기업·언론 등 다른 생산주체 자료의 교차검증
- 핵심 주장에는 당대 원문 1건과 다른 생산주체의 당대 자료 1건 이상을 목표로 한다.
- 후대 기관사·사사만으로 확인되는 내용은 ‘후대 서술’로 표시한다.

## 주제 유지 조건

다음 가운데 네 항목 이상을 1주일 안에 충족한다.

- [ ] 공동개발안 원문 전체와 생산맥락 확인
- [ ] 정부·ETRI 당대 자료 2종 이상 확보
- [ ] 1986~1989년 관련 기사 10건 이상 정리
- [ ] 참여기업 2곳 이상의 당대 기록 접근 가능성 확인
- [ ] 반도체연구조합 자료 접근 가능성 확인
- [ ] 직접 선행연구 5편을 읽고 중복되지 않는 질문 확인

## 축소안

연구조합·기업의 당대 자료를 확보하지 못하면 ‘행위자 간 협상’을 주장하지 않는다. 이 경우 연구를 **공업발전법의 산업정책 언어와 공동개발안의 제도 설계를 비교하는 정책사**로 축소한다.
