## 2. 확립된 원칙 — 반드시 지킬 것

### 2-1. 사료 판정 네 단계

**[확인] / [미확인] / [부재확인] / [존재불가]** 를 구별해 쓴다. **없다는 것을 확인한 것(부재확인)도 사료다.**

### 2-2. 서지는 원본으로 대조한 뒤 확정한다

- **법령은 예외 없이 관보나 연혁으로 대조한다.** 이 원칙은 실제로 오기 세 건을 잡아냈다(공업발전법 제10237호→**제10233호**, 시행령 제11904호→**제11937호**, 기술개발촉진법 시행령 제11883호→**존재하지 않음**).
- **공문서에도 오기가 있다.** 국회사무처가 만들어 영구 보존한 조합육성법 처리상황표의 공포일이 「1986년 5월 21일」인데 관보는 **5월 12일**이다.
- **재인용은 재인용임을 밝힌다.** 계획 문서 인용은 대부분 송성수의 보고서에서 재인용한 것이며 각주마다 명기했다.

### 2-3. 판본을 확정한 뒤 인용한다

**파일명의 연도를 그대로 믿지 않는다.** 같은 책의 다른 스캔본은 오프셋이 다르고, 목차의 시작 면도 다르다. **판본마다 오프셋을 실측하고 목차 첫 면을 먼저 확인한다.**

### 2-4. 인과와 순서를 구별한다

시간 순서만 확인된 것을 인과로 쓰지 않는다. 예 — 대통령 지시(1986.2.20) 직후 넉 달 반 계류하던 공사법안이 이틀 만에 처리된 것은 **순서만 밝히고 촉발 여부는 단정하지 않는다.**

### 2-5. 참여와 주도를 구별한다

장기계획 작업반 명단에 삼성·금성·현대·공사·ETRI가 모두 있으나, **명단은 이름과 소속만 전하므로 참여의 사실만 쓰고 역할은 단정하지 않는다.**

### 2-6. 인용 제약

- 신문 기사는 **최소 인용 + 지면 대조** 원칙
- 다른 에이전트의 미검증 산출물(`gazette_archive_audit_4m_dram.md`, `pa_archive_audit_4m_dram.md`, `riss_kci_academic_audit_4m_dram.md`, 수정된 `offline_primary_source_compendium.md`, `media_success_narrative_audit_2024_2026.md`)은 **검증 전 커밋·논거 사용 금지**
- **API key는 어떤 저장소 파일에도 기록하지 않는다**
- `git add`는 **명시적 경로만** 쓴다

## 5. 작업 방법

### 5-1. 렌더링

```bash
cd "/c/Users/user/OneDrive/바탕 화면/1980년대 전자공업/drafts" && "/c/Users/user/AppData/Local/Programs/Quarto/bin/quarto.cmd" render thesis_proposal_draft.qmd --to typst
```

### 5-2. 이미지 PDF 판독

```bash
pdftoppm -r 95 -png -f <시작> -l <끝> "파일.pdf" "출력경로/접두사"
```

판독이 갈리는 대목은 **`-r 260`에 `-x -y -W -H` 크롭**을 걸어 재확인한다. 이 방법으로 「상공부로 하자」가 「명시하지 말고 단순히 주무부처로 규정하자」의 오독임을 잡았다.

### 5-3. 각주 검증 — 커밋 전 반드시

```bash
for k in 라벨1 라벨2; do u=$(grep -c "\[\^$k\]" drafts/thesis_proposal_draft.qmd); d=$(grep -c "^\[\^$k\]:" drafts/thesis_proposal_draft.qmd); [ "$u" = "2" ] && [ "$d" = "1" ] && echo "$k ok" || echo "$k PROBLEM u=$u d=$d"; done
```

**사용 1회 + 정의 1회 = 총 2**가 정상이다. 렌더 경고(`Duplicate note reference`, `defined but not used`)도 확인한다.

### 5-4. 국회 의안정보시스템

`likms.assembly.go.kr/bill/bi/bill/sch/detailedSchPage.do?detailedTab=billDtl`에서 `document.forms['form']`의 `billNm` 또는 `billNo`에 값을 넣고 `fnSearch(1)` 호출. 상세는 `billDetailPage.do?billId=<id>`.

### 5-5. 국회기록원

`nara.go.kr` 국회기록물 > 일반문서. `frm_search`의 `search_text`에 검색어, `facet2Cd=1990`이 **1981~1990년** 구간. 원문은 `/search/generalRecordViewer.do`에 POST → iframe `src`에서 PDF 주소 추출 → `curl -L`로 내려받는다.

**핵심 판정 넷.**

1. **계획이 먼저다 — 그리고 생각보다 훨씬 먼저다.** 4M D램은 1985년 12월 장기계획 초안에 이미 1단계 과제였다. **더 나아가 「반도체 ＋ 공동개발 ＋ 전기통신공사」의 결합은 1984년 6월 29일 제3회 기술진흥심의회 안건 「半導體 技術跳躍을 위한 共同開發計劃」에 이미 있었다**(제출기관 과학기술처·전기통신공사등). **재가보다 2년 2개월, 공사법 개정안 제출보다 1년 4개월 앞선다.**
   - **다만 집적도는 다르다.** 1984년 12월 연감의 특연사 반도체 목표는 **256K~1M DRAM**이고 4M은 없다. **1984년 6월 안건이 어느 집적도를 겨냥했는지는 미확인이며, 안건 원문 확보가 최우선 과제다.**
   - **재원 규모는 계획 밖이었다** — 1986년도 특연사 계획 650억(민간 150억) 대 실적 987억(민간 470억). **재가는 과제를 만든 결정이 아니라 규모를 키운 결정이다.**
   - **이 판정에 대조군 둘이 붙었다** — 1982년도는 계획 60억 대 실적 47.6억(반도체·컴퓨터), 1985년도는 계획 403억 대 실적 442억. **어긋난 것은 1986년뿐이고, 어긋난 쪽은 정부가 아니라 민간이다.**
   - **사업의 형식도 새로 고안된 것이 아니다.** 1982년판 연감 〈표Ⅲ-2〉가 **「핵심전략기술 ＝ 정부출연연구소·민간기업·대학 공동개발, 정부·민간 투자」**로 유형을 이미 규정해 두었다.
2. **조항은 문서에는 있었으나 말해지지 않았다.** 공사법 제12조 제3항은 체신부 제안설명서에도, 구두 제안설명에도, 상임위 주요논의사항에도 없다. 국회사무처 요지서만이 두 항 중 하나로 짚었다.
3. **심의는 형식이었다.** 세 법률 모두 실질 논의가 없었고, 소위원회는 속기록을 남기지 않았으며(1981~90년 107건이 모두 「회의결과보고」), 공사법 소위는 41분에 다섯 법률을 처리했다. **당대 의원이 이를 「사전에 숙의의 과정을 거치지 않고 사후에 추인하는 형태」라 불렀다.**
4. **행정부 내부의 조정 장치도 그 재원에 닿지 않았다.** 과학기술처는 **과학기술진흥법 제4조 제1항**에 따라 정부예산으로 수행하는 연구개발사업을 사전 종합조정했다(A·B·C 등급). **그런데 1985년도 조정 대상 12개 기관 목록에 한국전기통신공사는 없고 상공부 본부도 없으며, 1983년도에 들어 있던 정부출연연구기관은 1985년도에 빠졌다.** → **[부재확인]** `source_card_science_yearbooks_1981_1989.md` §3-11. **국회 밖일 뿐 아니라 행정부의 사전 조정 밖이기도 했다는 근거다.**
