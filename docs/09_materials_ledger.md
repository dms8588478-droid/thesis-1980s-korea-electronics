# 09 — 자료 대장: 저장소 폴더는 이미 전수 조사되어 있다

**작성 2026-08-17.** 전수조사 결과와, 같은 자료를 두 번 읽지 않기 위한 판정.

---

## 0. 결론부터

**저장소의 자료 파일은 373개다. 그 가운데 363개가 이미 사료 카드나 조사 보고서나 계획서에 이름이 나온다.** 이름이 나오지 않는 열 개는 국회 의안 스캔본으로 파일명이 의안번호(`120050_10.PDF` 따위)일 뿐 **내용은 해당 법률 카드에 들어 있다.**

> **곧 폴더는 사실상 전수 조사되어 있다.** `research/source_card_folder_remainder.md`가 **2026년 8월 11일에 「폴더 보유 자료 전체의 논문 관련 부분 검토가 완료됐다」고 선언한 것이 지금도 유효하다.**

**그러므로 폴더 안의 자료를 「새 자료」로 다루는 일이 있어서는 안 된다.** 새로 들어온 파일인지 아닌지는 아래 3절의 방법으로 판정한다.

## 3. 중복이 일어난 자리 — 되풀이하지 않기 위한 기록

**2026년 8월 15~17일에 이미 조사된 것을 다시 조사한 사례 넷이다.**

| 다시 조사한 것 | 이미 있던 카드 | 무엇이 잘못되었나 |
|---|---|---|
| **재가 문서 원본**을 「저장소에 있었다」며 새로 읽음 | `source_card_1986_gongdong.md`(**08-08**) | 총사업비 879억·연차별·조달 분담·**대통령 친필**·**연구비 상환**이 모두 이미 [확인]이었다 |

### 그럼에도 새로 얻은 것

**중복이 전부는 아니었다.** 재가 문서에서 **기자재비 479억의 조달(산업기술향상자금 200 + 조합사 279)**, **「1分科組合社」**, **분담·합동·개별 연구의 구분**, **참고8의 외국 사례**, 추진 경위 다섯 시점, 이사장 姜晉求는 기존 카드에 없던 것이다. **그 부분만 `source_card_presidential_approval_1986.md`에 남기고 겹치는 부분은 기존 카드를 가리키도록 고쳤다.**

## 4. 판정 절차 — 자료를 손대기 전에

1. **`research/00_index.md`를 연다.** 자료의 성격으로 절을 찾아 카드가 있는지 본다
2. 카드가 있으면 **조사일과 판정**을 본다. **[확인]·[대조필]이면 다시 하지 않는다**
3. 카드가 없어 보이면 **파일명의 낱말로 `research/`를 검색한다** — 파일명과 카드 제목이 다른 경우가 많다

```bash
grep -rl "검색어" research/ docs/ drafts/
```

4. 그래도 없으면 새 자료다. 조사한 뒤 **카드를 만들고 `research/00_index.md`에 한 줄 더한다**
5. **기존 자료의 보유분이면 새 카드를 만들지 않고 기존 카드에 절을 더한다**

> **유보를 새로 달기 전에도 같은 절차를 밟는다.** 「대조가 남았다」고 적기 전에 그 대조가 이미 끝났는지 검색한다. **위 3절의 둘째 사례가 그것을 지키지 않아 생겼다.**
