## 0. 결론부터

**저장소의 자료 파일은 374개다. 그 가운데 364개가 이미 사료 카드나 조사 보고서나 구상에 이름이 나온다.** 이름이 나오지 않는 열 개는 국회 의안 스캔본으로 파일명이 의안번호(`120050_10.PDF` 따위)일 뿐 **내용은 해당 법률 카드에 들어 있다.**

> **곧 폴더는 사실상 전수 조사되어 있다.** `research/source_card_folder_remainder.md`가 **2026년 8월 11일에 「폴더 보유 자료 전체의 논문 관련 부분 검토가 완료됐다」고 선언한 것이 지금도 유효하다.**

**그러므로 폴더 안의 자료를 「새 자료」로 다루는 일이 있어서는 안 된다.** 새로 들어온 파일인지 아닌지는 아래 3절의 방법으로 판정한다.

## 4. 판정 절차 — 자료를 손대기 전에

1. **`research/00_index.md`를 연다.** 자료의 성격으로 절을 찾아 카드가 있는지 본다
2. 카드가 있으면 **조사일과 판정**을 본다. **[확인]·[대조필]이면 다시 하지 않는다**
3. 카드가 없어 보이면 **파일명의 낱말로 `research/`를 검색한다** — 파일명과 카드 제목이 다른 경우가 많다

```bash
grep -rl "검색어" research/ docs/ drafts/
```
